# Secure Multi-Branch Retail Network and Mini SOC

## Project Status
In development

## Project Overview
This project designs a secure Cisco enterprise network for a retail company with a Colombo head office, two retail branches and centralized security monitoring.

## Business Problem
POS systems, staff computers, CCTV devices and guest users must be separated to prevent unauthorized access and reduce the impact of cyberattacks.

## Planned Technologies
- Cisco Packet Tracer
- VLAN segmentation
- Inter-VLAN routing
- OSPF
- DHCP and DNS
- NAT/PAT
- Extended ACLs
- SSH administration
- AAA authentication
- Centralized Syslog
- Port security
- Site-to-site connectivity

## Security Objectives
- Isolate payment systems from users and IoT devices
- Prevent guest access to internal networks
- Centralize authentication and security logs
- Provide secure communication between company locations
- Monitor the network from a dedicated SOC workstation
